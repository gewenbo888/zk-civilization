# Psy Protocol — ZK Civilization OS · Psy 协议 · 零知识文明 OS

The systems-level companion essay-site to [Psy Protocol](https://psy.psyverse.fun). A bilingual (EN / 中文) treatment of zero-knowledge proofs, recursive verification, and trust evolution from kinship to mathematical civilization. Built around the thesis that civilizations scale through ever-improving trust systems — and that ZK is the first new trust primitive in 400 years that does not require a central authority.

The site is single-page and includes an animated prover-verifier-recursion diagram, a seven-layer trust evolution stack (kinship → religion → empire → bureaucracy → bank → platform → cryptographic), a seven-layer Psy Protocol architecture (field → hash → circuit → prover → recursion → consensus → application), a five-system consensus comparison table, a six-card mathematics-as-infrastructure timeline, a seven-narrative ideology grid (privacy / trustless coordination / programmable truth / math replacing institutions / network civilization / cryptographic sovereignty / civilization-scale computation), an AI + ZK futures grid, a six-card risks-and-contradictions section, and a seven-dial civilization simulator that maps any configuration onto a known trust archetype.
